# Management Scripts

- [Cleanup/Uninstall](./uninstall.md) a script that removes all side effects of a Royal Server installation
- [Prepare a Managed Server](./prepare-managed-server.md) a script that prepares a server to be managed by Royal Server
- [Grant Service Account Rights](./grant-service-account-rights.md) a script that grants a Royal Server service account other than `LOCAL SYSTEM` the user rights needed to run Dynamic Folder and Dynamic Credential scripts
